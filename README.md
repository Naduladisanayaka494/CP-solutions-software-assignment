# CP-solutions-software-assignment

Java solutions for standard programming problems.

## Problems Included

- **Problem 1 (`Problem1.java`)**: Compute the sum of numbers in a list using a for-loop, while-loop, and recursion.
- **Problem 2 (`Problem2.java`)**: Combine two lists by alternating elements.
- **Problem 3 (`Problem3.java`)**: Compute the list of the first 100 Fibonacci numbers.
- **Problem 4 (`Problem4.java`)**: Arrange a list of non-negative integers to form the largest possible number.
